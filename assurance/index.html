Decision Severity Matrix

Im wyższy koszt błędu, tym silniejsza bramka.

Tryb assurance jest dobierany według krytyczności, odwracalności decyzji, jakości danych i wymaganej odpowiedzialności.

LEVEL 01 / REVIEW

Standardowy przegląd

Identyfikacja luk, ograniczeń i podstawowych zabezpieczeń.

LEVEL 02 / MATERIAL

Ocena materialnego ryzyka

Scenariusze negatywne, dowody i warunkowa rekomendacja.

LEVEL 03 / CRITICAL

Release / authorization gate

Twarde kryteria akceptacji, pełny audit trail i plan remediacji.

LEVEL 04 / CONTINUOUS

Nadzór ciągły

Monitoring zmian, driftu, incydentów i ponownej walidacji.
